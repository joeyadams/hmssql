Description

The database's schema, read from its catalog views: every user table and view with its columns, their declared types (SqlType), the primary key, the unique constraints and the foreign keys.

tables <- readTablesIn conn "dbo"
forM_ tables $ \t -> forM_ (tableColumns t) $ \c ->
  putStrLn (T.unpack (objectName (tableName t) <> "." <> colName c <> ": " <> maybe (colTypeName c) sqlTypeName (colType c)))

Everything comes from sys.objects, sys.columns, sys.types and the constraint views, in one request. A column's type is resolved through an alias type (dbo.phone, based on varchar(20), is a varchar(20); sysname is nvarchar(128)), and a CLR user-defined type or a type newer than this library leaves colType Nothing with the name in colTypeName.

What is not read: indexes, check constraints, triggers, the referential actions of foreign keys, identity seeds, procedures and functions.

Fields

  • colName :: !Text
     
  • colId :: !Int

    column_id: a column's position, with gaps where columns were dropped.

  • colTypeName :: !Text

    The type the column is declared with, as named: a system type (nvarchar, sysname, vector, hierarchyid), or a user-defined type with its schema (dbo.phone).

  • colType :: !(Maybe SqlType)

    The type with its arguments, an alias type resolved to what it is based on. Nothing for a CLR user-defined type other than hierarchyid, geometry and geography, and for a type newer than this library.
