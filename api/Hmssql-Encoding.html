Description

Turning Haskell values into parameters.

ToSqlField encodes one value as one parameter, with a fixed wire type per Haskell type (Hmssql.Types has the table); ToSqlRow encodes a value as a list of parameters: a tuple, a record with a derived instance, a list, Only, or NamedParams. A new ToSqlField instance is usually contramap over an existing encoder; one that must choose the wire type itself builds a FieldEncoder, or the caller sends a RawParam. A large value can be read as it is sent, rather than held in memory; see Hmssql.Encoding.

Sending a large value

A parameter is normally encoded into memory before it is sent. binaryStream and textStream instead read the value as it is sent, so a value of any size can come from a file or a socket without being held in memory:

import qualified Data.ByteString as B
import Control.Monad (unless)
import Streaming (lift)
import qualified Streaming.Prelude as S
import System.IO (IOMode (..), withBinaryFile)

fileSource :: FilePath -> Source B.ByteString
fileSource path = Source $ \use -> withBinaryFile path ReadMode (use . chunks)
  where
    chunks h = do
      chunk <- lift (B.hGetSome h 65536)
      unless (B.null chunk) (S.yield chunk >> chunks h)

insertDocument :: Connection -> FilePath -> IO Int64
insertDocument conn path = execute conn $
  "INSERT INTO dbo.documents (payload) VALUES (" <> param (binaryStream (fileSource path)) <> ")"

A Source opens what it needs when sending starts and closes it when sending ends, so a Query built on this one can be sent again. sourceOf wraps a stream you already have, which can be sent only once. These rules come with it:

  • A source must not make a request on its own connection, which throws ReentrantSource. On a MARS connection it may read a stream that was opened earlier.
  • If a source throws, the request is abandoned, the exception reaches the caller, and the connection stays usable.
  • An output parameter can't be streamed.

A lazy ByteString or Text parameter is read as it is sent too, without any of this. To stream a large value in a result instead, see Hmssql.Decoding.

data ParamValue Source #

An in-memory value (Nothing is NULL), lazy bytes read as they are sent, or a source run as it is sent. A request holding either of the last two can be sent only once; a query builds a new request each time it is sent.

The constructors are public so that libraries can inspect and build values.

newtype Source a Source #

class ToSqlRow a where Source #

Types that can be sent as a list of parameters: the @p1, @p2, ... of mkQuery, or a row of executeMany or bulkInsert. Derive it for a record whose fields are ToSqlField types, one parameter per field in order:

data NewCustomer = NewCustomer { newName :: Text, newBirthDate :: Maybe Day }
  deriving stock (Generic)
  deriving anyclass (ToSqlRow)

Tuples of up to ten fields, (), Only, a list of one ToSqlField type, a list of SqlParam to mix types, and NamedParams have instances.

Named parameters

type NamedParam = (Text, SqlParam) Source #

A parameter's name and its value.

newtype NamedParams Source #

Parameters that the SQL text refers to by name. The leading @ is optional. A name must be a T-SQL variable name, and not of the form @pN, which is reserved for the positional parameters; the query functions check both before sending anything. Bulk copy matches the names, with that one @ removed, against the table's columns (Hmssql.BulkCopy).

mkQuery "UPDATE dbo.customer SET email = @email WHERE id = @id"
  (NamedParams [("email", SqlParam newEmail), ("id", SqlParam customerId)])
