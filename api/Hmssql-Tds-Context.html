Hmssql.Tds.Context

Description

Runtime state that affects how TDS messages are serialized and parsed.

Every get/put function in "Hmssql.Tds.*" takes a TdsContext so that protocol-version-dependent encodings are decided in one place.

data TdsVersion Source #

Protocol versions this library can negotiate.

TDS 7.4 is the baseline (SQL Server 2017 and later, Azure SQL). TDS 8.0 is the same token stream over TLS from byte zero ("strict" encryption).

data TdsContext Source #

The protocol state a connection has negotiated, which the encoders and parsers take as an argument; connectionContext reads a connection's.

  • tdsTransaction :: !(Maybe TransactionDescriptor)

    Current transaction, sent in the ALL_HEADERS of every request.

  • tdsUtf8Support :: !Bool

    Server acknowledged the UTF8_SUPPORT feature extension.

  • tdsCollation :: !(Maybe ByteString)

    The session's default collation, the five bytes of the last SQL collation ENVCHANGE (at login, and after a USE), if any: what a string is sent with where a collation is needed and none is known (a sql_variant value in Hmssql.BulkCopy).
