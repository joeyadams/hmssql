Description

The pure conversions of SQL Server's scalar values, and the type checks the field decoders make.

A reader is given exactly its value's bytes, whether they lay in one packet or several, so it knows nothing about packets, and a wrong length is an ordinary Left. Offsets into the bytes stay inside this module.

Character values

columnTextDecoder :: TypeInfo -> Either String (ValueReader Text) Source #

Compile a decoder for a character column. Unicode types are UTF-16LE. Single-byte types are decoded according to their collation's code page (see Hmssql.Tds.CodePage); a collation whose code page hmssql can't decode (a double-byte code page, or an unknown collation) is rejected.
