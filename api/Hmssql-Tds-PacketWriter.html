Hmssql.Tds.PacketWriter

Description

Writing a message straight into packet buffers, a packet at a time. This module alone owns a packet's storage and its framing. A producer writes ordinary Builders, except the bulk row writer and the scalar parameter path, which poke a value held in memory (unsafeWriteSized).

A packet's storage stays private until its last write. The writer then lets go of it, and only then is it the ByteString a sink receives, so no ByteString ever refers to memory that is still being written. What belongs in front of a packet, such as an SMP header, is the sink's to send beside it.

writeBytes :: PacketWriter -> ByteString -> IO () Source #

Copy bytes into the message, across packets as needed. Nothing of the source is kept once it has been copied, and a full packet goes to the sink when the next byte arrives.

writeBuilder :: PacketWriter -> Builder -> IO () Source #

Run a Builder into the packets. A primitive that needs more contiguous room than the packet has left is written to a small buffer of its own, whose bytes fill the current packet and continue in the next, and a chunk the builder inserts goes through writeBytes.

unsafeWriteSized :: PacketWriter -> Int -> (Ptr Word8 -> IO ()) -> IO () Source #

Write exactly n bytes by poking them: straight into the current packet when they fit, and otherwise staged in a buffer of their own and copied as writeBytes copies. The action must write all n bytes from the pointer it is given, read nothing there, and keep no reference to it. This is for the two producers that compute a write's size and its pokes from one description of a value: the bulk row writer, and the scalar parameter path in Hmssql.Tds.Parameter.
