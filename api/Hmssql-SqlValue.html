Hmssql.SqlValue

Description

A value of any SQL Server type, for code that handles columns and parameters whose types are only known at runtime: serving any table, copying rows between tables, a REPL.

Decoding: SqlValue is a FromSqlField that accepts any column (sqlValueDecoder), and SqlRow a whole row with its columns (sqlRowDecoder, sqlRowDecoderFor); queryMulti and callProcedure return every result set as SqlRows. A sql_variant decodes as its base type.

Encoding: SqlValue is a ToSqlField sent as the type its constructor names, so SELECT @p1 gives the same value back; SqlNull is an nvarchar(max) NULL, which the server converts to most types but not to binary or sql_variant.

ToSqlField SqlValue Source #

Each constructor is sent as the wire type FromSqlField SqlValue decodes it from, so SELECT @p1 returns the same SqlValue: SqlXml as xml (UTF-16 with a byte order mark, no schema collection), SqlText as nvarchar, and so on. SqlNull is an nvarchar(max) NULL, which the server won't convert to sql_variant (error 206).
