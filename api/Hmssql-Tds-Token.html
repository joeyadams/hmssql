data ColumnInfo Source #

A column of a result set, as its COLMETADATA describes it.

Constructors

ColumnInfo 

Fields

  • columnName :: !Text

    The name, or empty for an unnamed expression.

  • columnType :: !TypeInfo

    The wire type; columnSqlType names the SQL type.

  • columnFlags :: !Word16

    MS-TDS 2.2.7.4 Flags: nullable (columnIsNullable), identity, updatable and the rest.

  • columnUserType :: !Word32

    The UserType field: 0x50 for rowversion, greater than 0xFF for alias types, and 0 for other types. An alias ID does not carry its name; columnType describes its underlying storage type.

  • columnTableName :: !(Maybe [Text])

    Only present for text, ntext and image columns.

columnIsNullable :: ColumnInfo -> Bool Source #

Whether the column may hold NULL.

columnIsLong :: ColumnInfo -> Bool Source #

Whether a column's values may be of any length: a max type, xml, json, a CLR type, or a legacy text, ntext or image, which arrive in pieces rather than behind a length of at most 8,000 bytes. Such a column is the one to read with a FoldingCell or streamField.

readToken :: Maybe ResultSetInfo -> Parser Token Source #

One token as a recipe, given the current result set's columns. It reads from the parser's input and suspends when that runs out, so nothing here knows about packets, sessions or the end of a message.

readTokenWith :: Int -> Maybe ResultSetInfo -> Parser Token Source #

readToken with the bound on allocating ahead of a value's bytes.

readTokenSkipping :: Maybe ResultSetInfo -> Parser Token Source #

readToken for a drain, which skips values rather than assembling them.

doneOf :: Token -> Maybe Done Source #

The DONE, DONEPROC or DONEINPROC a token is, if it is flagged as failed (DONE_ERROR or DONE_SRVERROR). In a response with no ERROR token that is all the server says of a failed request (SevereError).

isFinalDone :: Token -> Bool Source #

A DONE-family token without MORE ends the response.
