# hmssql documentation

There are two sections.

**[The guide](guide/README.md)** is for people using hmssql: how to
connect, write queries, stream results and values, use transactions, bulk
copy and MARS, and how it works underneath, a short page each. Start
there.

**[docs/dev](dev/README.md)** is for people working on hmssql itself: the
design and the alternatives it rejected, what the protocol and the server
actually do, the limitations, the backlog, the tests, the bugs found, the
research records of MARS, Windows, value streaming and performance, and
the history.

The [README](../README.md) is the introduction. The Haddock of the
`Hmssql` module is the reference. [examples/](../examples/README.md) has complete programs.
